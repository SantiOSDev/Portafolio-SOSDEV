# SOSDEV — Presentación del repositorio

Este repositorio muestra el sitio corporativo de SOSDEV, una empresa que combina desarrollo de software, automatización e inteligencia artificial para ayudar a las empresas a optimizar procesos y crecer con soluciones digitales.

## ¿Qué es este repositorio?

Es el código fuente de una página web corporativa construida con Next.js. El proyecto incluye:

- Una experiencia visual inmersiva y moderna.
- Un formulario de contacto con envío seguro mediante SMTP.
- Canales de comunicación directa como WhatsApp y correo.
- Un diseño pensado para transmitir profesionalismo, confianza y tecnología.

## ¿Qué hace SOSDEV?

SOSDEV crea sistemas digitales que vuelven más eficiente la operación de empresas y equipos:

- Desarrollo de aplicaciones web a medida.
- Automatización de tareas y flujos de trabajo.
- Integración de APIs y datos.
- Implementación de infraestructura digital confiable y escalable.
- Uso de inteligencia artificial para optimizar decisiones y procesos.

## Valor diferencial

SOSDEV no entrega solo un sitio web: entrega soluciones integradas.

- Enfoca la tecnología en resolver problemas reales.
- Prioriza claridad visual y experiencia de usuario.
- Conecta datos, servicios y automatizaciones para reducir trabajo manual.
- Diseña sistemas que pueden escalar y adaptarse con el crecimiento del negocio.

## Tecnologías y estructura

Este proyecto utiliza:

- Next.js
- React
- TypeScript
- CSS moderno y diseño responsivo
- Envío de correo desde el backend con SMTP
- Docker para despliegue opcional

Archivos clave:

- `app/page.tsx` — contenido y estructura principal del sitio.
- `app/globals.css` — estilos, paleta de colores y adaptaciones móviles.
- `app/ContactForm.tsx` — formulario de contacto.
- `app/api/contact/route.ts` — validación y envío de mensaje.
- `app/layout.tsx` — metadata, iconos y configuración general.
- `public/` — imágenes, iconos y recursos estáticos.
